# 潮汐之间 · 视觉升级版

这是一个可直接部署到 Render 等静态/Node 托管环境的版本，保留原站的实时 3D 海岸、心情选择、聊天、声音设置和呼吸练习。

## 运行

```bash
node server.js
```

默认地址：`http://127.0.0.1:4183`

## 视觉升级

- 重新设置日落与月光的天空、云层、海面反光、雾色和曝光。
- 增加主光、冷色海面补光、人物暖色轮廓光和更细的接触阴影。
- 重做两个角色的头身比例、五官、发束、服装层次、围巾和饰物。
- 对话改为人物头顶浮字并自动飘散；海景上只保留底部输入框。
- 陪伴文字采用逐字打印机效果，完整显示后停留 4.2 秒再缓慢消散；主角改为半透明、菲涅尔边缘发光的玻璃史莱姆。
- 加入远景帆船、沙滩颗粒和夜间月光反射。
- 海滩上的留声机是真实场景物件，点击机身即可搜索并试听 iTunes 免费音乐。
- 海滩漂流瓶支持收取其他访客的树洞、回信，以及写下自己的心事重新放入大海；内容持久化在 `data/bottles.json`。
- 夜间点击天空可触发流星。
- 增加可点击的治愈贝壳和自动淡出的场景介绍。
- 界面使用更克制的海玻璃质感、细边高光、分层阴影和更清晰的字体层级。
- 保留原有功能，并针对 390px 手机视口重新调整人物取景和界面间距。

## 模型连接

默认通过 Pollinations 免费模型在线回应，无需用户填写密钥。网络不可用或模型限流时会自动回退到离线陪伴。也可以通过页面右上角“模型连接”填写自己的 OpenAI 兼容接口，或在部署环境配置：

```text
CHAT_PROVIDER_URL
CHAT_API_KEY
CHAT_MODEL
```

`server.js` 包含最小可用的静态服务、状态检查和兼容接口转发。
