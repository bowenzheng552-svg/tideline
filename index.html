A LITTLE CONNECTION

让陪伴，更懂你

小屿已准备好离线陪伴。连接模型后，每一次回应都由你的模型生成。

离线陪伴已就绪精选对话，随时可以开始聊天。

模型可由服务端统一配置，也可以由每个人在下方填写自己的模型；密钥只在调用时发送给服务端，不进前端代码。

连接你的大模型

不想依赖服务器配置时，直接填你自己的模型即可。信息只保存在本机浏览器，每次聊天会随请求发送给服务端代为调用。

开发者接入说明

在部署环境设置以下变量：

CHAT_PROVIDER_URL
CHAT_API_KEY
CHAT_MODEL

接口接收 messages、model 与 temperature 字段，支持返回 reply 或 choices[0].message.content。

POST /api/chat
{ messages: […], mood: "平静", scene: "sunset" }

GET /api/status 可读取连接状态。源码中的 README 包含完整接入示例。
